# FAQ Telegram Bot

Телеграм-бот на **aiogram 3.24.0** для ответов на вопросы из DOCX и рассылки уведомлений о багфиксах.

## Возможности

- **Вопрос-ответ из DOCX**: бот читает файл `faq.docx`, ищет ближайший вопрос по смыслу и возвращает ответ.
- **Уведомления о багфиксах**: подписка пользователей и рассылка сообщений командой администратора.

## Структура FAQ

Файл `data/faq.docx` должен содержать пары вопросов и ответов. Поддерживаются форматы:

- Строки с префиксами `Q:` / `Вопрос:` и `A:` / `Ответ:`.
- Если префиксов нет, первая строка считается вопросом, следующие — ответом до следующего вопроса.

Пример:

```
Q: Как восстановить пароль?
A: Нажмите «Забыли пароль?» и следуйте инструкции.
```

## Запуск

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Установите переменные окружения:

```bash
export BOT_TOKEN="ваш_токен"
export ADMIN_IDS="123456789,987654321"
export FAQ_DOCX="data/faq.docx"
export SUBSCRIBERS_PATH="data/subscribers.json"
```

3. Запустите бота:

```bash
python src/main.py
```

## Команды

- `/start` — приветствие.
- `/help` — подсказка по использованию.
- `/subscribe` — подписка на багфиксы.
- `/unsubscribe` — отписка.
- `/bugfix <текст>` — отправка уведомления подписчикам (только для админов).
